# JoshMahal

Project site for JoshMahal, a Rajput sandstone palace designed for 7080 N Invergordon Road, Paradise Valley, Arizona.

The site is plain static HTML, CSS and JavaScript. It has no build step and is served by GitHub Pages from the repository root.

## What's here

- `index.html` is the single page. It covers exteriors, interiors, 360° views, earlier studies, the drawing set, the program, specifications and the budget.
- `img/full`, `img/thumb` hold the renderings as web-optimised JPEGs.
- `img/pano` holds the equirectangular 360° panoramas.
- `img/dwg`, `img/dwgthumb` hold the 12 sheets of schematic design set SD-01.
- `downloads/` has the full PDF drawing set and the DXF CAD files.
- `fonts/` holds Rozha One and Hind (SIL Open Font License).
- `vendor/` holds Pannellum 2.5.6 (MIT), the 360° viewer.

## Notes

The renderings are AI-generated design interpretations, not photographs. The drawings are schematic and not for construction. Final design, engineering and permitting require an Arizona-registered architect and engineers.
